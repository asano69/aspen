# Cardpod

Cardpod is a card box for thinkers.

<img src="../frontend/public/favicon.svg" width="100" align="right" />



## Purpose
- アイデアや言葉を保存する汎用的なカード箱
- 

## Uses
- 本や動画やブログなどの興味深いアイデア・言葉を保存する。
- 自分が思いついたこと・考えたことを保存する。

## Features
- Cardpodでは同一ページを複数人でリアルタイムに共同編集できます。
