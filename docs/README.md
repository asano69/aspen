# Cardpod

Cardpod is a card box for thinkers.

<img src="../frontend/public/favicon.svg" width="100" align="right" />



    cardpod export out.zip --dir=pb_data


## Purpose
- アイデアや言葉を保存する汎用的なカード箱
- 

## Uses
- 本や動画やブログなどの興味深いアイデア・言葉を保存する。
- 自分が思いついたこと・考えたことを保存する。

## Features
- リアルタイム共同編集
- 実ファイル・編集バッファの双方向同期
- 分散型識別子を用いたフェデレーション 

## Tech Stack
### backend
- Go
- PocketBase v0.39+
- blevesearch/bleve

### frontend
- Solid.js v1.9
- Kobalte v0.13+
- dnd-kit v0.5.0
- CodeMirror6
